# Dimension 2: Style & Aesthetic (The Skin Library)

This library contains 67+ modern UI styles categorized by industry and interaction goals.

## 🏢 General Purpose Styles (49)
- **Glassmorphism:** Frosted glass, transparent layers, depth.
- **Aurora UI:** Vibrant mesh gradients, luminous effects.
- **Soft UI Evolution:** Neumorphism 2.0 with accessibility fixes.
- **Linear/Vercel:** Minimalist dark mode, 1px borders.
- **Bento Grid:** Modular, information-dense, structured.
- **Claymorphism:** 3D inflated, playful, tactile.
- **Minimalist Luxury:** Max white space, serif typography.
- **Brutalism:** Raw, bold, geometric, high-contrast.
- **Y2K Revival:** Metallic, chrome, retro-futuristic.
- **Organic/Biomorphic:** Nature-inspired, flowing.
- **Cyberpunk:** Neon, glitch, high-energy tech-noir.

## 🚀 Landing Page Specific Styles (8)
- **Feature-Rich Hero:** Large visuals, centered value props.
- **Storytelling Scroll:** Immersive horizontal/vertical transitions.
- **Immersive Gallery:** Full-bleed imagery for luxury/ecommerce.
- **Trust-First System:** Clean, social proof-heavy components.

## 📊 Dashboard & Analytics Styles (10)
- **Modular Modular Cards:** High data density with clarity.
- **Glass Dash:** Transparent overlays for creative tools.
- **System Dark:** High-performance, low eye-strain developer interfaces.
