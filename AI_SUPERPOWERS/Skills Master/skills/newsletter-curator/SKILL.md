# 🗞️ The Newsletter Curator

This skill automates the entire lifecycle of an industry-leading newsletter. It leverages NotebookLM for deep research and synthesis, and AntiGravity for orchestration, template generation, and external API integrations.

## Core Automations (Weekly Auto)

The following checklist represents the automated flight path for this skill:

### 1. Scrape 20 Industry Sources ✅
* **Description:** Automatically pulls the latest articles, posts, and news from a predefined list of 20 high-value industry targets.
* **AntiGravity Action:** Run a scheduled web scraping script (or API calls to RSS feeds/aggregators) to collect the raw URLs and text content.
* **NotebookLM Integration:** Use `mcp_notebooklm-mcp_source_add` to pipe all 20 curated URLs or text dumps directly into a dedicated weekly Newsletter Notebook.

### 2. Research Trending Topics ✅
* **Description:** Identifies the highest-leverage and most talked-about topics from the scraped data to focus the newsletter's narrative.
* **NotebookLM Integration:** 
  * Use `mcp_notebooklm-mcp_notebook_query` to ask: *"What are the top 3 trending topics or debates across all sources provided?"*
  * Alternatively, run a fresh `mcp_notebooklm-mcp_research_start` (mode: `deep`) to pull in supplementary context around a specific trending keyword identified from the scrape.

### 3. Generate Curated Briefing ✅
* **Description:** Synthesizes the raw data into a highly readable, engaging, and structured newsletter briefing.
* **NotebookLM Integration:** 
  * Use `mcp_notebooklm-mcp_studio_create` with `artifact_type: "report"` and `report_format: "Blog Post"` or `"Briefing Doc"`.
  * Supply custom instructions to enforce a specific brand voice, ensuring it reads like a human-written, premium newsletter.

### 4. Create Visual Highlights ✅
* **Description:** Generates compelling visual assets to break up the text and increase engagement (e.g., charts, infographics, or summary cards).
* **NotebookLM / AntiGravity Integration:**
  * Use `mcp_notebooklm-mcp_studio_create` with `artifact_type: "infographic"` to summarize the top trends visually.
  * Use AntiGravity's `generate_image` tool to create custom header graphics or specific conceptual illustrations to accompany the written briefing.

### 5. Build Email Template ✅
* **Description:** Formats the generated briefing and visuals into a responsive, beautifully designed HTML email template.
* **AntiGravity Action:** AntiGravity takes the markdown briefing and generated image URLs, and injects them into a pre-designed premium HTML/CSS email framework. It ensures all links, tracking text, and CSS are mail-client safe.

### 6. Schedule Send ✅
* **Description:** Connects to your email service provider (e.g., Mailchimp, ConvertKit, SendGrid) to schedule the final delivery.
* **AntiGravity Action:** Execute a custom Python/Node script utilizing the target email provider's API to create a new campaign, upload the HTML template, set the subject line (generated by NotebookLM), and schedule it for the optimal weekly send time.

## Execution Requirements
- **NotebookLM MCP:** Must be authenticated to ingest sources and generate the briefing/infographic.
- **External APIs:** Requires API keys for the chosen Email Service Provider (ESP) configured in the local environment.
- **Source List:** A local JSON or CSV file containing the 20 target industry URLs/RSS feeds.
