# Interactive Book Translator

## Overview
This skill standardizes the translation and localization process for *The Interactive Book of Prompting*. It ensures that the tone, technical accuracy, and UI consistency are maintained across all supported languages.

## Triggers
- Requests to translate or localize book chapters.
- Localizing UI strings for prompts.chat.
- Ensuring consistency in technical prompt terminology across languages.

## Workflow
1. **Tone Check**: Ensure the translated content matches the engaging and instructional tone of the original book.
2. **Technical Accuracy**: Verify that technical AI terms (e.g., "temperature", "top-p") are translated correctly or kept in English if appropriate for the target audience.
3. **Consistency**: Use the localized strings index to ensure matching across the book and the prompts.chat UI.

## Target
Localized versions of the book at prompts.chat.
