# Frontend Design

## Overview
This skill moves beyond "AI-generated" boilerplate to create premium, hand-crafted user interfaces. It emphasizes design thinking, motion, and visual excellence.

## Allowed Tools
- `shadcn/ui`, `framer-motion`
- `tailwind-config`
- `lucide-react`

## Triggers
- Building new web components.
- Designing full pages or landing pages.
- Requests for "premium" or "wowed" UI.

## Workflow

1. **Visual Vision**
   - Define a unique color palette and typography scale before coding.
   - Establish a design system for consistent radii, shadows, and spacing.

2. **Aesthetic Implementation**
   - Avoid generic "blue/white" defaults; use curated, harmonious themes.
   - Use smooth gradients and glassmorphism where appropriate.

3. **Motion & Interaction**
   - Add subtle micro-animations for hover states and transitions using Framer Motion.
   - Ensure interfaces feel "alive" and responsive.

## Core Rules
No "AI slop" or generic layouts. Every element should feel intentional and polished.
